 🇮🇳 Rape Cases in India | Data Analysis 2018–2022

A data-driven analysis of reported rape cases in India from 2018 to 2022, using SQL and Excel to examine state-wise patterns, Union Territory trends, minor-victim statistics, and case-verdict outcomes.

 🔍 Key Analysis

 🗺️ State-wise & UT-wise comparison of reported cases
 📅 Year-wise analysis from 2018–2022
 👧 Analysis of cases involving minors
 ⚖️ Examination of final court verdict outcomes
 📊 Identification of states and UTs with notably higher or lower reported cases
 🔎 SQL-based data extraction, transformation, and analysis

 💡 Key Insights

 📍 Rajasthan recorded the highest total number of reported cases during the period.
 👧 Goa recorded the highest share of reported cases involving underage victims.
 🏙️ Delhi accounted for a substantial share of reported UT-level cases.
 📉 Nagaland and Sikkim recorded the lowest reported case counts among the states analyzed.
 ⚖️ The analysis also examined the gap between reported cases and cases reaching a final court verdict.

> 📌 Note: This analysis is based on reported data and should not be interpreted as representing the complete incidence of crime, as reporting and recording practices can affect the observed figures.

 🧠 Analytics Approach

Data → SQL Analysis → Excel Validation → Visualization → Insights

The project demonstrates how structured data analysis can be applied to a sensitive social issue while focusing on evidence-based patterns rather than assumptions.
